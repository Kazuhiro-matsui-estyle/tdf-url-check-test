# tdf-url-check-test

TDF AI Search の「外部URL更新チェック」機能の動作確認に使うリポジトリです。

このファイルを書き換えると、アプリ側で「更新あり」が検知されます。

## 使い方

1. TDF AI Search の管理画面（`/#/admin`）→「URL管理」を開く
2. 「新規登録」から、下の raw URL を登録する

   ```
   https://raw.githubusercontent.com/Kazuhiro-matsui-estyle/tdf-url-check-test/main/README.md
   ```

3. 「今すぐ更新チェック」を実行する → 「更新」列はグレーのまま（更新なし）
4. このファイルを GitHub 上で編集して commit する
5. 数分待ってから「今すぐ更新チェック」を再実行する → 「更新」列のボタンが有効になる（更新あり）

週次の自動チェック（毎週日曜 03:00 JST）でも同じ判定が行われます。

## 補足

- 更新の判定は、取得した本文のハッシュと、アプリに取り込み済みの本文のハッシュを比較して行われます
- 「更新あり」のフラグは、管理画面から再取得するまで立ったままになります
- raw.githubusercontent.com は数分間キャッシュされるため、編集直後のチェックでは反映されないことがあります
